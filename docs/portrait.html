三个核心结论

① AI 领军人才 = 8 维能力 × 长期主义 × 跨太平洋学术训练

60 位样本中，8 个核心维度（D1 原创算法 / D2 系统工程 / D3 学术地位 / D4 创业 / D5 政策治理 / D6 长期主义 / D7 跨界整合 / D8 公共影响）能完整刻画 100% 样本的能力组合；长期主义（D6 质心 1.93）和跨太平洋学术训练是最高维度的成功要素——Hinton/Bengio/LeCun/Sutton 30+ 年坚守 + Demis Hassabis 14 年 DeepMind 坚持 + 梁文锋 18 年从量化到 DeepSeek。证据：matrix.md 60×8 分数 + dimensions.md 8 维定义 + audit_group1-5 60 人逐 D 维 L0 事实引用。

② 60 人聚成 6 个领军原型：P1 学术源流 / P2 工业研究院 / P3 学术+AI 创业 / P4 跨界整合 / P5 AI 治理 / P6 商业硬件

③ 中西方分工清晰：中国 30 人 = "实业化+政策对接+学术+创业"四位一体；西方 30 人 = "原始创新+思想市场+独立治理+多栖跨界"四位一体

如何追溯单条评分

任意一个 D 维分数的证据链：

  1. 在 60×8 矩阵中找到人物 + D 维（如"梁文锋 / D3 / 0 分"）
  2. 打开对应审计报告（如 audit_group5_entrepreneur_cn.md 的"梁文锋"小节）
  3. 查看表格"v3 分数 / v4 拟改 / L0 事实支撑 / 评分理由"四列
  4. 从"L0 事实支撑"列的 L1-NNN 编号回溯到 data/atomic_abilities/ 和 data/fact_cards/ 源文件

审计模板（含刘铁岩完整样板）见 audit_template.md。3 个应用脚本（apply_v4*.py）记录了 v3→v4 全部修订的执行轨迹。
