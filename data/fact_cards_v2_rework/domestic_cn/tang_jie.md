## 1. 教育背景

- **1992 年**：考入四川省南充市营山中学（班主任李忠耀评价"考试不那么看重分数，看重的是把知识点彻底弄懂"）；
- **1995 年**：考入**燕山大学**（原东北重型机械学院）**自动化专业**（"中国重型机械院校之王的王牌专业"）——这是**最关键的早期事实修订**：原 fact card 误写为吉林大学本科，实际是燕山大学；
- **1999 年（推算）**：在燕山大学**转专业至计算机**，硕士同样在燕山大学计算机科学与技术专业，导师背景为控制 / 自动化方向；
- **2002 年**：于燕山大学获得计算机科学与技术专业**硕士学位**；同年考取**清华大学计算机科学与技术系**博士研究生，导师为**李涓子**（清华计算机系教授、知识图谱与 NLP 专家、孙茂松的弟子），形成"孙茂松 → 李涓子 → 唐杰"三阶师承链；
- **2006 年 6 月**：在清华大学计算机科学与技术系获得**工学博士学位**，博士论文获清华大学优秀博士论文二等奖（2006 年度）；
- **2006 年起**：清华大学计算机系讲师、副教授、教授（2012 升教授，2019 升长聘讲席教授）。

**关键转折点：**
- **"燕山大学 → 清华大学"的二次跃升**：唐杰本科与硕士均在燕山大学（位于河北秦皇岛，原属东北重型机械学院体系，1997 年更名为燕山大学），是"中国重型机械院校之王的王牌专业"；博士选择赴清华让他从"燕山大学 / 自动化背景"成为"清华 AI 核心圈"成员；
- **从"自动化"到"计算机"的赛道转换**：在燕山大学本科读自动化，硕士转计算机科学，博士再到清华师从李涓子研究语义 Web 与数据挖掘——这种"工科 + 控制" + "计算机 + 知识图谱"的复合背景，让他后来做知识图谱 + 大模型有独特的工程化思维；
- **博士论文奖金 = 2 万块启动资金**：唐杰回忆博士毕业后留清华做科研，最初没有项目经费，拿出 2 万元的博士论文奖金作为项目启动资金，做出了 AMiner 的原型——这是"以个人赌注启动国家级学术基础设施"的典型。

## 3. 核心研究方向 / 技术贡献

**主线 1：知识图谱与社会计算。**
- **AMiner 系统**：从 2006 年开始构建的学术网络分析平台，2011 年后正式命名为 AMiner；目前拥有 1 亿+ 学者档案、3 亿+ 论文关系、覆盖 220 个国家/地区、800 万+ 独立 IP 用户，是全球最大的学术网络平台之一；
- **OpenKG**：开源的中文知识图谱，2024 年已收录 100+ 个高质量知识图谱；
- **学术影响力分析**：提出了 AuthorRank、PaperRank 等基于图的影响力分析算法，被 Google Scholar、Web of Science 等系统参考；
- **社会网络 + 知识图谱融合**：把"实体关系"与"社会关系"统一到一个异构信息网络中分析，提出了多个代表性算法。

**主线 2：图神经网络与异构信息网络。**
- 唐杰团队是图神经网络（GNN）研究的中国代表团队之一，提出了多个 GNN 变体（如 HAN、HGT 等）；
- 在 KDD、WSDM、WWW、AAAI 等顶会发表了大量异构信息网络论文；
- 唐杰本人在 SIGKDD 2021 获 Test-of-Time Award（十年最佳论文奖），是国内学者获此奖的第一人。

**主线 3：GLM 系列大语言模型（智谱 AI 主导）。**
- **GLM（General Language Model）**：唐杰团队 2020 年起提出的基于"自回归填空"预训练范式的大语言模型，与 BERT、GPT 形成三大主流预训练范式；
- **GLM-10B（2020）**：100 亿参数基座模型；
- **GLM-130B（2022.8）**：中英双语千亿级超大规模预训练模型，斯坦福大学大模型中心评测亚洲唯一入选；
- **ChatGLM / ChatGLM-2 / ChatGLM-3 / GLM-4（2023-2024）**：智谱 AI 主导的对话大模型系列，是国内最早开源的大语言模型之一；
- **CogVLM / CogAgent / CogVideoX**：智谱的多模态大模型系列；
- **GLM-4-Plus / GLM-4.5 / GLM-4.6 / GLM-4.7 / GLM-5（2024-2026 规划）**：智谱在长上下文（128K-200K）、Agent、Coding 等方向的代表产品；
- **Z.ai**：智谱的海外品牌（Z 是字母表最后一个字母，代表终极境地）。

**主线 4：AI 治理与政策研究。**
- 担任科技部新一代人工智能治理专委会委员；
- 在《Nature Machine Intelligence》《中国科学》等期刊发表多篇关于 AI 治理、AGI 风险、AI 与社会的研究论文。

## 8. 失败 / 争议 / 挫折

- **AMiner 的"国际化天花板"**：AMiner 虽然在中国学术界占据主导地位，但在国际学术界的影响力仍落后于 Microsoft Academic（已停服）和 Semantic Scholar——这反映了中国学术基础设施"先内后外"的典型路径。
- **GLM 的"开源 vs 闭源"路线争议**：智谱在 GLM 系列上采取"开源（学术版）+ 闭源（商业版）"双轨路线，被部分开源社区批评"既不像 Meta LLaMA 那样完全开源，也不像 OpenAI 那样完全闭源"——这一争议在 2024 年后逐步缓解（智谱在 2024 年中开源了 GLM-4 多个版本）。
- **智谱与智源的"内部竞争"风险**：唐杰既是智源理事长又是智谱创始人，智源孵化的其他大模型公司（如月之暗面、面壁智能）可能与智谱形成竞争——这种"国字号 + 商业公司"的双重身份在治理上需要持续平衡。
- **大模型商业化压力**：智谱 2022-2024 累计亏损 30+ 亿元（2024 净亏损 24.66 亿元），研发投入 8 倍于营收；2025 年净亏损 47.18 亿元，2025 年 ARR 17 亿元、毛利率 41%——商业化能力 vs 巨额投入的张力是常态。
- **AGI 时间表的"乐观主义"风险**：唐杰在 2024 年多次访谈中表示"AGI 在 10 年内可实现"，但与张钹、朱军等"AGI 是 20-30 年科学问题"的判断不同——这一"乐观主义"让他在智谱的产品规划上可能承担更大风险。
- **DeepSeek 的"警醒"**：唐杰在 2026.1.8 内部信中公开承认"DeepSeek 的出现警醒了我们"——DeepSeek 以"低成本 + 高智能 + 全开源"颠覆了商业模式，对智谱的闭源 + API 路线形成冲击，迫使智谱"重新做了一次比较系统的'强化'"。
- **杨植麟"出走后"形成的新竞争**：唐杰的学生杨植麟 2023 年创办月之暗面（Kimi），2025 年估值 43 亿美元——这种"师徒同行竞争"在中国 AI 圈是典型的"学派分散"现象。

## 10. 个人哲学 / 方法论

**核心方法论："科研就像登山，一定要登到顶峰，不登顶就是失败"——这是他在 2026.6 财富号专访中的开篇语。**

1. **"数据 + 知识 + 算力"三要素框架**：唐杰多次在公开访谈中提出，大模型的下一阶段突破需要"数据（数量 + 质量）+ 知识（图谱 + 推理）+ 算力（高效 + 绿色）"三要素的协同，这一观点影响了中国大模型的研究方向。

2. **"让机器像人一样思考"**：智谱自始至终的愿景和理想，也是智谱人持之以恒奋斗的唯一目标。2018 年底，在人脑认知的双系统理论的启发下，唐杰团队设计了一个拥有"快思考 + 慢思考"的机器"认知"系统。2019 年智谱正式成立，开始尝试探索 AGI。

3. **"上瘾"哲学**："为什么我们要戒咖啡呢？上瘾也不一定是坏事呀，如果我们做研究能像喝咖啡一样上瘾，又何愁做不好呢？"（杨强语，引自唐杰 2026.1.8 内部信）

4. **"强化学习"方法论**：唐杰在 2026.1.8 内部信中将 2024-2025 的复盘定义为"强化学习"——"我们喊出了'定力'与'成就'的口号……年初的时候，一切都那么难，模型效果达不到预期，全国上下价格战，杀出重围需要找到一个精准的突破口。我们坚守了阵地，终于找到 Coding 作为突破口。"这是"把 RL 思想用于企业经营"的隐喻。

5. **"开源 + 商业化"双轮驱动**：智谱采取"开源学术版 + 闭源商业版"路线（GLM-4.5 / 4.6 / 4.7 开源，同时 API / 私有化部署收费），是他"既要做基础研究，又要做产业落地"哲学的体现。

6. **"长期主义 + 平台型思维"**：智谱从 2019 年成立到 2026.1.8 港股上市的 7 年时间里，他坚持"先把模型做好，再谈商业化"——这种"先技术后商业"的姿态与同代"先商业后技术"的 AI 创业公司形成对比。

7. **"AGI 是 10 年的事"**：与 OpenAI / Anthropic 的"AGI 即将来临"叙事不同，他主张"AGI 是 10 年尺度的工程问题，需要技术 + 政策 + 社会的协同"。

8. **"中国 AI 必须自主创新"**：他多次在公开场合强调"中国 AI 不能永远跟着美国走，必须在'通用预训练 + 知识增强'上走出自己的路"——这一观点直接驱动了 GLM 的"自回归填空"预训练范式的提出。

9. **"师承 + 合作"的工作方式**：从博士到教授到创业，他的核心合作者（李涓子、刘知远、张鹏）几乎都是 10+ 年以上的长期合作——这是典型的"清华 NLP 学派"工作方式。

10. **"学术-工业-政策"三位一体**：作为清华教授 + 智谱创始人 + 智源理事长 + CCF 副理事长 + 政策咨询专家，他能在"学术、工业、政策"三个场域间无缝切换，这是中国 AI 学界"复合型领军人才"的典型。

11. **"咖啡精神"**：2026.1.8 智谱上市时，唐杰用"用'咖啡'的精神做 AGI"为题写内部信——这种"日常 + 仪式 + 信念"的三位一体，让智谱团队在 7 年艰苦创业中保持"内啡肽"而非"多巴胺"的动力。
