# 姜大昕 事实卡 v2（factcheck 版）

> **修正说明**：v1 事实卡中已正确标注"姜大昕 = 阶跃星辰（StepFun）创始人"。原任务描述"姜大昕（出门问问）"有误，出门问问创始人是李志飞。

## 1. 教育背景（已验证）

- 姜大昕，纽约州立大学布法罗分校计算机科学博士。
- 博士后在新加坡南洋理工大学计算机科学与工程学院任助理教授。
- 发表国际会议期刊论文近 200 篇，曾获 ACM SIGKDD 最佳应用论文奖。
- 研究方向：机器学习、数据挖掘、生物信息学、自然语言处理。
- 来源：百度百科"姜大昕"。

## 2. 早期职业轨迹（已验证）

- **2007** 加入**微软亚洲研究院（MSRA）**任首席研究员。
- 微软期间历任：首席研究员、微软亚洲互联网工程研究院（STCA）副院长、首席科学家、微软全球副总裁。
- 负责必应（Bing）搜索引擎、微软智能语音助手 Cortana、Azure 云、Microsoft 365 等核心产品的自然语言理解系统研发。
- 领导 400+ 人团队。
- 微软期间 16 年。
- **2023** 从微软离职。
- **2023-04-06** 创立**上海阶跃星辰智能科技有限公司（StepFun）**。
- 来源：百度百科"姜大昕"；今日头条"前微软 NLP 大牛姜大昕领衔阶跃星辰"（2024-04-03）。

## 3. 核心研究方向（已验证）

- **NLP 基础研究**：发表论文近 200 篇，获 ACM SIGKDD 最佳应用论文奖。
- **必应搜索 NLP 主管**：领导必应搜索全球搜索体验。
- **Step 系列大模型**（2023-）：
  - **Step-1**（2023 千亿参数语言大模型）：超越 GPT-3.5。
  - **Step-2**（2024 万亿参数 MoE 语言大模型，**国内首个由创业公司发布的万亿参数模型**）。
  - **Step-1V / Step-1.5V / Step-1.5V-mini**：千亿参数多模态模型。
  - **Step-1X**：图像生成模型。
  - **Step-Video-T2V**（300 亿参数，与吉利联合开源）：可生成 204 帧视频。
  - **Step-Audio 系列**（3B-130B 端到端语音大模型）。
  - **Step-3**（2025-07-25 发布）：首个全尺寸、原生多模态推理模型，**总参 321B / 激活 38B MoE 架构**。
- **22 款自研基座模型**，其中 16 款为多模态模型（占比超 70%）。
- 来源：阶跃星辰官网（stepfun.com）；2024 IEEE Fellow 名单。

## 4. 标志性成就（已验证）

- 2024-12 入选 **2025 IEEE Fellow** 名单（NLP + 大模型领域）。
- 2025-07 入选"**2025 中国 AI 盛典年度 AI 人物**"。
- 2024-12 完成数亿美元 B 轮融资（上海国投领投，腾讯、五源、启明等跟投），投后估值 20 亿美元（约 140-200 亿元人民币）。
- 2025-07 联合华为昇腾、沐曦、壁仞、燧原、天数智芯、无问芯穹、寒武纪、摩尔线程、硅基流动等近 10 家芯片厂商成立"**模芯生态创新联盟**"。
- 与吉利汽车深度合作：联合开源 Step-Video-T2V 与 Step-Audio。
- 与 OPPO、荣耀等头部国产手机厂商深度合作。
- 2025 收入目标 10 亿元（公开数据中 AI 六小虎最高年收入目标）。
- 2025-01-26 印奇（旷视科技创始人）出任阶跃星辰董事长。
- 来源：阶跃星辰官网；央视频 2025-07-26；中新经纬 2025-04-30。

## 5. 创业 / 领导经历（已验证）

- **上海阶跃星辰智能科技有限公司（StepFun，2023-04-06-）**：创始人、CEO、执行董事、法定代表人。
- 联合创始人：朱亦博（系统负责人，前微软/字节/谷歌，万卡集群建设管理经验）、焦斌星（数据负责人，前微软必应核心搜索团队负责人）、李璟（副总裁，商业化）。
- 核心团队成员还包括 **张祥雨**（ResNet 作者之一，旷视出身）。
- 公司核心使命："智能阶跃，十倍每一个人的可能"。
- 技术路线："单模态 → 多模态 → 多模理解和生成的统一 → 世界模型 → AGI"。
- 来源：阶跃星辰官网。

## 6. 跨界 / 影响力溢出（已验证）

- **多模态卷王**：22 款自研基座模型，16 款多模态。
- **开源生态**：Step-Video-T2V、Step-Audio 系列、Step-3 等多个核心模型开源。
- **产业联盟模式**：发起"模芯生态创新联盟"。
- **终端 Agent 战略**：手机（OPPO/荣耀）+ 汽车（吉利）+ IoT + 金融（券商）+ 机器人（智元/乐森）多行业终端 Agent 落地。

## 7. 性格特质与认知风格（已验证）

- **基础研究导向**：自评"坚持做基础大模型的公司会越来越少"。
- **长线 + 高投入**：理解"AGI 时代需要长期投入"，不追求短期商业化。
- **科学化训练方法**：与智谱"科学训模"类似。
- **架构创新驱动**：MFA 注意力机制、AFD 分布式推理系统等。
- **方法论清晰**："Scaling（已知 + 未知）+ 技术创新（架构创新 / 知识压缩 / 记忆 / 持续学习）+ 多模态感统"是 2026 三大方向。

## 8. 失败 / 争议 / 挫折（已验证）

- **"冒泡鸭"产品停运（2024-12）**：C 端产品商业化不达预期。
- 公司副总裁李璟坦言"暂时还达不到盈利水平"。
- **"OpenAI 模仿者"质疑**：2024-2025 一度被批评"过于跟随 OpenAI 路线"。
- 客户获取与定制化压力：B 端客户决策周期长、定制化多、标准化程度低。

## 10. 个人哲学 / 方法论（已验证）

- **"AI 三阶段演进"**：单模态 → 多模态 → 多模理解生成统一 → 世界模型 → AGI。
- **"Scaling 是已知 + 未知"**。
- **"知识记忆 + 持续学习"**：未来模型必须具备"短期记忆、工作记忆、长期记忆"+"持续学习能力"。
- **"多模态感统"**：借鉴人类感知统合系统。
- **"以端到端 / 全异步 / 工程化的训练系统为支撑"**。
