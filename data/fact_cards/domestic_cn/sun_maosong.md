## 1. 教育背景

- 1980–1984 年：清华大学计算机系本科；
- 1984–1987 年：清华大学计算机系硕士（自然语言处理方向，师从**黄昌宁**——清华 NLP 早期开拓者）；
- 1987–1990 年：清华大学计算机系博士（师从黄昌宁）；
- 1990 年：博士毕业留校任教，开始清华 NLP 的建设之路；
- 1994–1996 年：英国剑桥大学（Cambridge University）计算机实验室访问学者（合作导师为**Steve Young**，剑桥大学工程系主任、语音识别领域奠基人之一）。

**关键转折点：**
- **师承黄昌宁（清华 NLP 奠基人）**：黄昌宁是 1980 年代中国 NLP 的代表学者之一，师承他让孙茂松直接站在中国 NLP 的"第一梯队"上——这构成了清华 NLP"黄昌宁 → 孙茂松 → 李涓子 / 唐杰 / 刘知远"三阶师承链；
- **剑桥 2 年访学的国际视野**：1994–1996 年在剑桥大学跟随 Steve Young 学习，让他接触了"统计 NLP / 语音识别 / 机器学习"的国际前沿方法——这次访学让他从"规则式 NLP"转向"统计式 NLP"，为他后来在清华建立"统计 NLP"研究主线埋下伏笔；
- **"34 岁从 0 到 1 建立 THUNLP"**：1999 年 5 月（37 岁）他正式创立清华大学 NLP 实验室（THUNLP），这是中国 NLP 研究的"黄埔军校"。

## 2. 早期职业轨迹

- 1990 年：博士毕业留清华大学计算机系任教；
- 1992 年：晋升副教授；
- 1994–1996 年：英国剑桥大学访问学者；
- 1997 年：晋升教授（35 岁）；
- 1999 年 5 月：正式创办**清华大学 NLP 实验室（THUNLP）**，任创始主任——这一实验室后来培养了唐杰、刘知远、李涓子、刘洋等中国 NLP 学界 / 产业界的领军人才；
- 2000 年代：与李涓子、王东等共同建设"知识图谱与社会计算"研究主线；
- 2007–2014 年：担任清华大学计算机系副主任；
- 2014–2019 年：担任**清华大学计算机系主任**（系主任任期 5 年）——这是清华计算机系历史上任职时间最长的系主任之一；
- 2018 年：参与筹建**清华大学人工智能研究院**，任**常务副院长**（院长为张钹）；
- 2018 年起：担任**智源研究院副理事长**，参与智源"悟道"系列大模型建设；
- 2019 年：参与筹建 THUNLP 大模型团队，主导"GLM"系列基础研究；

**关键选择：**
- **"35 岁从讲师到教授"的快速晋升**：他在清华从讲师一路晋升到教授只用了 7 年（1990–1997），是清华计算机系历史上最年轻的教授之一——这反映了他在 NLP 领域的快速突破；
- **"34 年扎根清华" 的坚持**：从 1984 年本科入学到 2024 年仍在清华带学生，孙茂松在清华工作了 40 年——这种"长程、深度、体系化"的师承路线是他与同代 NLP 学者最显著的差异；
- **"学界为主，产业支持为辅" 的姿态**：与同代"明星 AI 创业者"（如王小川、刘知远）不同，孙茂松本人基本不参与商业化，而是以"清华 NLP 学派的精神领袖"角色，通过"培养弟子 + 学术指导 + 智源副理事长"间接影响中国 AI 产业。

## 3. 核心研究方向 / 技术贡献

**主线 1：自然语言处理基础理论与方法。**
孙茂松是中国本土**最被国际同行认可的"中文 NLP 基础研究"学者之一**。代表性工作：
- **中文分词 / 词性标注 / 句法分析**：1990–2000 年代系统研究中文基础 NLP 问题，是中文信息处理早期代表人物之一；
- **统计机器学习 + NLP**：2000 年代起把统计学习方法系统引入清华 NLP，是清华从"规则式 NLP"转向"统计式 NLP"的关键推手；
- **深度学习 + NLP**：2010 年代起把深度学习方法引入清华 NLP，是清华 NLP 团队的"深度学习转型"领袖。

**主线 2：知识图谱与社会计算。**
- **知识图谱 + NLP 融合**：与李涓子、唐杰等共同构建"知识图谱 + NLP"的研究主线，是 OpenKE、THU-OpenKG 等开源项目的学术支持者；
- **社会计算 + NLP**：与唐杰等共同构建 AMiner 学术网络分析平台（虽然主要由唐杰主导，但孙茂松是 THUNLP 的主任支持者）；
- **学术影响力分析**：与唐杰、刘知远等合作发表多篇学术影响力分析论文。

**主线 3：中文信息处理与中文计算。**
- **中文信息处理标准**：参与中国中文信息处理相关国家标准制定；
- **中文大模型**：作为智源副理事长、THUNLP 主任，他主导或参与"GLM / CPM / ERNIE"等中文大模型的基础研究；
- **中文信息处理学术组织**：担任中国中文信息学会（CIPS）理事长（2018–2022），是中文信息处理学界"掌门人"。

**主线 4：大语言模型时代的研究。**
- **GLM 系列**：作为 THUNLP 主任，他是 GLM（General Language Model）系列研究的核心学术支持者；
- **悟道 1.0/2.0/3.0**：作为智源副理事长，他参与悟道系列大模型的整体规划与学术指导；
- **CPM 系列**：与刘知远、车万翔等合作的"中文预训练模型"系列。

## 8. 失败 / 争议 / 挫折

- **"中文 NLP 国际化" 的挑战。** 1990–2000 年代，THUNLP 是中国 NLP 的核心，但中文 NLP 在国际上的影响力始终落后于英文 NLP——这反映了"中文信息处理"的天然语言壁垒。
- **"GLM 命名争议"。** 唐杰团队 2020 年提出的 GLM 与 Google 2019 年提出的 GLM（Generalist Language Model）同名——业内对这一命名有不同意见。
- **"大模型商业化"的间接性。** 清华 NLP 学派（孙茂松 → 唐杰 / 刘知远）虽然在中国大模型领域具有"国家队"地位，但商业化层面始终不及月之暗面、智谱等同代公司——这种"学界强、产业弱"的不平衡是清华系大模型的共性问题。
- **"AI 治理"立场的相对温和。** 孙茂松在 AI 治理、AI 伦理讨论中相对"温和"——这与 OpenAI / Anthropic 的"激进"立场形成对比。
- **"清华 NLP 学派'分散化'的隐性风险"。** THUNLP 培养的弟子虽然覆盖了几乎所有头部 AI 公司，但学派的"分散化"也对凝聚力构成挑战——这是"成功学派的代价"。

## 10. 个人哲学 / 方法论

**核心方法论："AI 是科学问题，不是工程问题" + "做 NLP 要有'坐冷板凳'的耐心" + "师承传承是 NLP 教育的核心"。**

1. **"AI 是长程的科学问题"**：孙茂松多次在公开场合表达"AI 不是 5-10 年就能解决的技术问题，而是 20-30 年尺度的科学问题"——这一观点影响了中国 AI 学界对"长期主义"的理解。
2. **"知识 + 数据"双轮驱动**：他主张"中文 NLP 的下一阶段突破必须结合'中文语言学知识'与'大规模数据'"——这一观点影响了中国 NLP 研究的"中国学派"建设。
3. **"师承传承是 NLP 教育的核心"**：他多次在公开场合强调"培养一个 NLP 学者需要 10 年，培养一个 NLP 学派需要 30 年"——这种"师承传承"意识是 THUNLP 25 年持续成功的核心。
4. **"做 NLP 要有'坐冷板凳'的耐心"**：他反对"为追风口而做研究"，主张"做 NLP 必须'板凳要坐十年冷'"——这一观点影响了中国 NLP 学界对"基础研究 vs 应用研究"的取舍。
5. **"AI 必须服务社会"**：他多次在公开场合表示"NLP / AI 应该服务于教育、医疗、社会公益"，"AI 不能只追求商业利益"——这是他"清华老派学者"立场的体现。
6. **"中国 NLP 必须自主创新"**：在 2024 年多次发言中，他强调"中文 NLP 不能永远跟着英文 NLP 走，必须建立自己的'中文 NLP 学派'"——这一观点影响了中国 NLP 研究的"中国学派"建设。
7. **"学界 + 政策 + 产业"三位一体**：作为清华教授 + 智源副理事长 + CIPS 理事长 + 政策咨询专家，他能在"学术、政策、产业"三个场域间无缝切换，这是中国 AI 学界"复合型领军人才"的典型。
