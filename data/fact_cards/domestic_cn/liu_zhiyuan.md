## 1. 教育背景

- 2006–2010 年：哈尔滨工业大学（哈工大）计算机科学与技术学院本科；
- 2010–2015 年：清华大学计算机系博士，导师为**孙茂松**（清华 NLP 创始人、THUNLP 主任）——这是他学术谱系的起点（"孙茂松 → 刘知远"是清华 NLP 最重要的师承链条之一）；
- 2015 年：博士毕业即留校任教，担任清华大学计算机系博士后 / 助理研究员。

**关键转折点：**
- **从哈工大到清华的"南下"**：哈工大是中国 NLP 早期重镇（拥有哈工大社会计算与信息检索研究中心 HIT-SCIR），但刘知远博士选择赴清华，让他从"东北 NLP 学派"进入"清华 NLP 学派"核心圈；
- **博士期间建立"知识图谱"研究主线**：在孙茂松的指导下，他博士期间奠定了"知识图谱 + NLP"的研究主线，发表多篇 ACL / EMNLP 顶会论文——这是他后来"知识增强大模型"研究的基础；
- **"30 岁以下清华副教授"的快速晋升**：他 2018 年（30 岁）晋升清华大学副教授，是清华计算机系历史上最年轻的副教授之一，反映了他在 NLP 领域的快速突破。

## 3. 核心研究方向 / 技术贡献

**主线 1：知识图谱与知识表示学习。**
刘知远是中国本土**最被国际同行认可的"知识图谱 + 知识表示学习"学者之一**。代表性工作：
- **TransE / TransH / TransR 系列**的知识图谱表示学习方法（与同门韩旭、同学林衍凯等合作），是知识表示学习的经典方法；
- **OpenKE**：开源知识图谱表示学习工具包，被全球研究者广泛使用；
- **知识图谱 + 预训练语言模型融合**：把"符号化知识"（图谱）与"分布式知识"（语言模型）融合，是 ERNIE、知识增强 LLM 等方向的代表学者。

**主线 2：预训练语言模型与大语言模型。**
- **ERNIE / ERNIE 2.0**：知识增强的预训练语言模型，是中国本土最早的大规模预训练模型之一；
- **CPM（Chinese Pre-trained Language Model）系列**：与智源、车万翔等合作的"中文预训练模型"系列，是 2020 年后中国大模型研究的标志性工作；
- **悟道 1.0/2.0/3.0**：作为智源核心团队成员参与悟道系列大模型设计；
- **MiniCPM**：面壁智能主导的"端侧大模型"，以"小参数 + 高性能"为特点，2024 年发布的 MiniCPM-2B/4B 系列在端侧设备上达到了与 7B-13B 模型相当的性能。

**主线 3：高效推理与端侧大模型。**
- **面壁智能的核心方向**：与同代大模型公司"卷参数规模"不同，面壁智能主打"高效推理 + 端侧部署"——这是刘知远"知识 + 效率"研究思路的延伸；
- **量化、稀疏激活、模型压缩**：刘知远团队在模型压缩、量化、推理加速方向发表了多篇代表性论文，是国内"高效大模型"研究的代表团队；
- **MiniCPM-V / MiniCPM-o**：多模态端侧大模型，2024 年发布后在端侧多模态评测中位列前茅。

**主线 4：开源生态建设。**
- **OpenBMB 开源社区**：2022 年创办的中国本土大模型开源社区，旗下项目包括：
  - **OpenBMB / BMTools**（大模型工具集）
  - **FlagAI**（早期智源大模型工具包）
  - **UltraChat**（多轮对话数据集）
  - **UltraFeedback**（大模型反馈数据）
  - **MiniCPM** 系列模型
  - **XuanYuan（轩辕）**预训练大模型系列
- 累计 GitHub 星数 50k+，是中国本土大模型开源生态的核心力量之一。

## 8. 失败 / 争议 / 挫折

- **"ERNIE"命名争议。** 2019 年刘知远团队发布的 ERNIE 与百度 2019 年发布的 ERNIE 同名（不同时期、不同团队）——业内常把这两者混淆，造成了一定的命名争议。
- **"CPM"系列的国际化挑战。** CPM 系列虽然在中国 NLP 社区具有重要地位，但在国际上的影响仍落后于 BERT、GPT、LLaMA 等——这反映了中国本土大模型"先内后外"的典型路径。
- **面壁智能的"端侧大模型"商业化压力。** 2024 年大模型竞争白热化，端侧大模型商业化路径仍不清晰（手机 / IoT / 边缘计算场景的"杀手级应用"尚未出现）——面壁智能需要在 2025-2026 年找到差异化的商业化路径。
- **学界 - 创业平衡的争议。** 国内学术圈对"教授兼职创业"长期存在争议，刘知远采取"首席科学家"模式（与同门朱军、唐杰类似）——这一模式的实际成效仍有待观察。
- **"OpenBMB 社区"的国际影响力。** OpenBMB 虽然在中国本土有相当影响力，但在国际开源社区的存在感仍弱于 Hugging Face、PyTorch 等——这是中国大模型开源生态的共性挑战。
- **同代竞争压力。** 清华 NLP 学派"四剑客"（孙茂松 → 李涓子 → 唐杰 → 刘知远）中，唐杰（智谱）走通用大模型路线，刘知远（面壁）走端侧 + 高效路线，韩旭（面壁 CEO）走 Agent 路线——学派内部的"同代竞争"既是压力也是动力。

## 10. 个人哲学 / 方法论

**核心方法论："知识 + 数据"双轮驱动 + "开源是 AI 研究的未来"。**

1. **"知识 + 数据"双轮驱动**：刘知远是"知识增强大模型"路线的代表人物，主张"大模型的下一阶段突破必须结合'符号化知识'（图谱、规则）与'分布式知识'（语言模型）"——这一观点与 OpenAI 的"纯数据驱动 + 规模即一切"路线形成对比。
2. **"长期主义 + 平台型思维"**：在 OpenBMB、面壁智能、清华 NLP 三线作战中，他坚持"做平台而不是做应用"、"做基础研究而不是做产品"——这种"平台型思维"是清华 NLP 学派的共同特征。
3. **"开源是 AI 研究的未来"**：OpenBMB 是他主导的核心开源项目，反映了他对"开源是 AI 研究的未来"的坚定信仰——这一观点对中国大模型开源生态具有重要意义。
4. **"高效 + 端侧"的差异化定位**：面壁智能主打"端侧大模型 + 高效推理"，与同代"卷参数规模"的同行形成差异化竞争——这一思路对中国大模型的"普及化"具有重要意义。
5. **"师承 + 合作"的工作方式**：从博士到教授到创业，他的核心合作者（孙茂松、唐杰、韩旭、林衍凯）几乎都是 5-15 年以上的长期合作——这是典型的"清华 NLP 学派"工作方式。
6. **"AI 是科学问题，不是工程问题"**：他主张"做大模型不能只跑实验，必须建立理论基础"——这一观点影响了中国大模型研究的方法论。
7. **"AI 必须服务社会"**：他多次在公开场合表示"大模型应该服务于教育、医疗、社会公益"，"AI 不能只追求商业利益"——这是他"清华老派学者"立场的体现。
