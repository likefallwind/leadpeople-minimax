# 印奇 事实卡

## 1. 教育背景

印奇，1987 年（或 1988 年）出生于安徽芜湖。2006 年毕业于安徽省芜湖市第一中学，高中没毕业便通过清华大学自主招生名额入选。**清华大学姚期智实验班（"姚班"）本科**；本科阶段在微软亚洲研究院（MSRA）实习并开始承担重大项目。2010 年清华毕业后在 MSRA 全职工作一年，研发人脸识别引擎（后被应用于 X-box 和 Bing 等产品）。**哥伦比亚大学（Columbia University）计算机视觉 / 3D 相机方向博士**，师从 Computational Camera 行业泰斗，**两年后回国正式创业**。

## 2. 早期职业轨迹

- 2006-2010 清华大学姚班本科 + MSRA 实习。
- 2010-2011 MSRA 全职工作 1 年，参与研发人脸识别引擎。
- 2011-2013 哥伦比亚大学博士（师从 Computaional Camera 泰斗），期间远程参与国内创业。
- **2011-10 与唐文斌、杨沐在清华园共同创立旷视科技（Face++）**——三人是清华姚班同班同学，被业内称为"旷视三巨头 / 清华姚班三剑客"。
- 2012 国内首款基于 iOS 的移动体感游戏"乌鸦来了"获清华大学第三十届"挑战杯"特等奖，一度冲上中国区 App Store 前五。

## 3. 核心研究方向 / 技术贡献

印奇个人的"学术硬贡献"较唐文斌（系统 / 编程竞赛）和杨沐（架构）为少，主要体现在**将"姚班系"计算机视觉 + 深度学习能力商业化、平台化**：

- **Face++ 开放平台**：构建云端 API、离线 SDK、面向用户的自主研发产品三类形态，将人脸识别技术广泛应用到互联网及移动应用场景。
- **人脸识别 + 图像感知**：旷视早期核心产品。
- **Brain++ 深度学习框架**（2014 起，旷视自研）：覆盖从数据管理、模型训练到模型部署的端到端能力，是中国最早的自研深度学习框架之一。
- **城市大脑 / 物联网（IoT）AIoT 解决方案**：从消费互联网（Face++ 平台）转向城市级、园区级、消费电子级的视觉 AI。
- **机器人 / 具身智能**：2018-起旷视进入"AIoT 时代"；后期加大具身智能投入（"机器人 + AI"）。
- **2024-2026**：印奇以"旷视系"资源继续参与阶跃星辰、机器人等多个 AI 项目（2026-01-26 印奇出任阶跃星辰董事长）。

## 4. 标志性成就 / 获奖 / 里程碑

- 2014 旷视超过 Google、Facebook 取得**人脸识别领域三大评测的世界第一**（FDDB、LFW、等多个）。
- 2014-12-17 新闻联播专门报道。
- 2014 中国最具投资价值企业 50 强。
- 2015 福布斯 30 Under 30 中国区创业奖。
- 2016 福布斯亚洲 30 Under 30 企业科技（Enterprise Tech）人物排行榜**首位**（28 岁）。
- 2016 作为中国创新企业代表与刘延东总理就"双创"概念交换意见。
- 2016 中关村海外人才创业支持资金 + 北京市海外高层次人才认定。
- 2017 第九届"中国青年创业奖"入围候选人。
- 2017-07 国务院总理李克强主持的经济形势座谈会上，印奇以旷视科技（Face++）CEO 身份与另外 5 位经济学家和企业家一同被邀请。
- 2026-01-26 **出任阶跃星辰董事长**——从"中国 AI 视觉三巨头之一"扩展到"多模态大模型领航者之一"。

## 5. 创业 / 领导经历

- **旷视科技（Face++，2011-10-）**：联合创始人、CEO、董事长。
  - 联合创始人：印奇（CEO）、唐文斌（CTO）、杨沐（架构）。
  - 团队核心均来自清华姚班 + MSRA + 哥伦比亚大学。
  - 2012 黑马大赛全国总冠军，联想之星数百万元天使投资。
  - 创新工场 A 轮百万美元融资；后续阿里、蚂蚁、富士康、启明、君联、GGV 等多轮。
  - 2019-08 港股递交招股书（后撤回）；2021 年再度递交，2022 年起反复冲刺。
  - 2024 起旷视业务重心从消费互联网视觉（Face++）转向城市 / 物流 / 消费电子 / 机器人等多场景 AIoT。
- **"旷视系"辐射**：印奇 / 唐文斌 / 杨沐三人中，印奇任旷视 CEO，唐文斌任 CTO，杨沐任架构师；后印奇出任阶跃星辰董事长，形成"旷视 → 阶跃"的视觉派与大模型派的跨公司联盟。

## 6. 跨界 / 影响力溢出

- **"姚班 + MSRA + 哥伦比亚"复合背景代表**：是"中国顶尖学术 + 海外工程 + 顶级 VC + 政府关系"四位一体创业路径的样板。
- **"Face++ 开放平台"是中国 AI 1.0 时代最具代表性的开放能力**。
- **具身智能 / 机器人**：旷视后期核心赛道之一。
- **跨公司生态**：通过阶跃星辰董事长身份、旷视系投资等参与大模型、机器人等核心赛道。

## 7. 性格特质与认知风格

- **极致的产品 / 工程师底色**：从大二起就在 MSRA 参与核心项目；自述"对人脸识别技术很着迷"。
- **"姚班系"清教徒式自信**：被业内评价为"具有姚班系'理工男+商业化野心'的双重气质"。
- **极强的政策敏锐度**：与刘延东、李克强等高层多次直接对话，是"AI 创业公司中政策敏感度最高"代表之一。
- **跨代际长期视角**：从 2011 创立到 2026 出任阶跃星辰董事长，是中国 AI 创业公司中"长期主义 + 跨赛道布局"的代表。

## 8. 失败 / 争议 / 挫折

- **港股 IPO 屡次受挫**：2019-08 递交招股书，2020 暂缓；2021 重新递表，2022 进一步推进；后因监管 / 市场 / 估值等因素多次推迟。
- **2019 列入美国实体清单**：旷视被美国商务部列入实体清单，对供应链、海外业务造成持续影响。
- **业务转型阵痛**：从"消费互联网 Face++ 平台"转向"城市 / 物流 / 消费电子 AIoT"过程中，营收结构与团队都需要重组。
- **估值波动**：从最高峰 60+ 亿美元到 IPO 推迟期间的估值下调。
- **隐私 / 数据合规争议**：人脸识别行业的隐私争议在旷视上多次成为舆论焦点（被部分评论视为"人脸识别第一案"代表性公司）。
- **"蚂蚁集团 IPO 暂缓连带影响"**：旷视与蚂蚁集团深度绑定，2020-11 蚂蚁 IPO 暂缓后旷视 IPO 进程也受波及。

## 9. 协作网络

- **清华姚班**：同班同学唐文斌、杨沐（联合创始人）；师承姚期智院士。
- **MSRA 体系**：印奇与汤晓鸥、孙剑（ResNet 作者之一、旷视首席科学家，2022 年去世）、张祥雨（ResNet 作者之一，旷视出身，2023 年加入阶跃星辰）等深度合作。
- **战略投资人**：阿里巴巴（蚂蚁）、富士康、创新工场（李开复）、启明、君联、GGV、博裕、阳光保险等。
- **政府关系**：北京市海淀区政府、中关村管委会；与刘延东、李克强等高层有直接对话渠道。
- **跨公司生态**：阶跃星辰（印奇任董事长）、张祥雨（ResNet 作者，旷视 → 阶跃星辰）、宇树科技（王兴兴）等具身智能公司。
- **政府合作**：与公安部一所、国家信息中心、北京市多个政府部门合作。

## 10. 个人哲学 / 方法论

- **"机器之眼"愿景**（2011 创立时即提出）："从人工智能技术出发研制'机器之眼'，用它读懂世界"。
- **"AIoT 时代"叙事**：从"互联网 + 视觉"到"AI + 物联网"。
- **"原创深度学习框架 Brain++"**：坚持"操作系统级"技术自研，而非"调用开源"。
- **"科技改变世界"**：自述"每个极客都有一个'科技改变世界'的梦想"。
- **"产业 + 政策双轮"**：在 AI 监管、隐私、伦理等议题上与政府深度合作。
- **"AI 1.0 → AI 2.0"**：从视觉专才到多模态 + 大模型 + 具身智能的延展。
