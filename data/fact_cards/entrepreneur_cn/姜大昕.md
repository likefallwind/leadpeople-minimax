# 姜大昕 事实卡

> ⚠️ **事实说明**：原任务描述中"姜大昕（出门问问）"有误。**姜大昕**是阶跃星辰（StepFun）创始人、前微软全球副总裁；**出门问问**的创始人是**李志飞**。本卡按"姜大昕 = 阶跃星辰创始人"的事实撰写。

## 1. 教育背景

姜大昕，纽约州立大学布法罗分校计算机科学博士；博士后在新加坡南洋理工大学计算机科学与工程学院任助理教授。发表国际会议期刊论文近 200 篇，曾获 ACM SIGKDD 最佳应用论文奖。研究方向覆盖机器学习、数据挖掘、生物信息学、自然语言处理。

## 2. 早期职业轨迹

- 2007 年加入**微软亚洲研究院（MSRA）**任首席研究员，开启在微软长达 **16 年**的职业生涯。
- 微软期间历任：首席研究员、微软亚洲互联网工程研究院（STCA）副院长、首席科学家、微软全球副总裁。
- 负责必应（Bing）搜索引擎、微软智能语音助手 Cortana、Azure 云、Microsoft 365 等核心产品的自然语言理解系统研发；领导 400+ 人团队。
- 2023 年从微软离职，2023-04-06 创立**上海阶跃星辰智能科技有限公司（StepFun）**。

## 3. 核心研究方向 / 技术贡献

- **NLP 基础研究**：发表论文近 200 篇，获 ACM SIGKDD 最佳应用论文奖。
- **必应搜索 NLP 主管**：领导必应搜索全球搜索体验。
- **Step 系列大模型**（2023-）：
  - **Step-1**（2023 千亿参数语言大模型）：超越 GPT-3.5。
  - **Step-2**（2024 万亿参数 MoE 语言大模型，**国内首个由创业公司发布的万亿参数模型**）：在 LiveBench 榜全球第 5、国内第 1，IF Average 86.57 超过 GPT-4o 与 Gemini-1.5。
  - **Step-1V / Step-1.5V / Step-1.5V-mini**：千亿参数多模态模型，Step-1.5V 性能比肩 GPT-4V。
  - **Step-1X**：图像生成模型。
  - **Step-Video-T2V**（300 亿参数，与吉利联合开源）：可生成 204 帧视频。
  - **Step-Audio 系列**（3B-130B 端到端语音大模型）：千亿参数端到端语音大模型；Step-Audio 2 mini 在多个国际基准 SOTA。
  - **Step-3**（2025-07-25 发布）：首个全尺寸、原生多模态推理模型，**总参 321B / 激活 38B MoE 架构 + 原创 MFA 注意力机制 + AFD 分布式推理系统**。
- **22 款自研基座模型**，其中 16 款为多模态模型（占比超 70%）。

## 4. 标志性成就 / 获奖 / 里程碑

- 2024-12 入选 **2025 IEEE Fellow** 名单（NLP + 大模型领域）。
- 2025-07 入选"**2025 中国 AI 盛典年度 AI 人物**"。
- 2024-12 完成数亿美元 B 轮融资（上海国投领投，腾讯、五源、启明等跟投），投后估值 20 亿美元（约 140-200 亿元人民币）。
- 2025-07 联合华为昇腾、沐曦、壁仞、燧原、天数智芯、无问芯穹、寒武纪、摩尔线程、硅基流动等近 10 家芯片厂商成立"**模芯生态创新联盟**"——**首次由模型企业牵头与上游算力厂商深度合作**。
- 与**吉利汽车**深度合作：联合开源 Step-Video-T2V 与 Step-Audio；端到端语音大模型首次量产上车（AI 智能座舱 Agent OS）。
- 与 **OPPO、荣耀**等头部国产手机厂商深度合作（手机端 AI 助手），已覆盖国内超过一半的头部国产手机厂商。
- 与**国泰君安、海通证券**等合作推出"AI 小财神"智能金融助手。
- 2025 收入目标 **10 亿元**（公开数据中 AI 六小虎最高年收入目标）；B 端收入占比超 80%。
- 与智元机器人、乐森机器人合作探索具身智能。
- 2025-01-26 **印奇出任阶跃星辰董事长**（与旷视印奇交叉任职）。
- Step-2 在 LiveBench 是**前十名内唯一国产大模型**，排前面只有 OpenAI、Anthropic。
- 被《麻省理工科技评论》列为除 DeepSeek 之外 4 家重要中国 AI 公司之一。

## 5. 创业 / 领导经历

- **上海阶跃星辰智能科技有限公司（StepFun，2023-04-06-）**：创始人、CEO、执行董事、法定代表人。
  - 联合创始人：朱亦博（系统负责人，前微软/字节/谷歌，万卡集群建设管理经验）、焦斌星（数据负责人，前微软必应核心搜索团队负责人）、李璟（副总裁，商业化）。
  - 核心团队成员还包括 **张祥雨**（ResNet 作者之一，旷视出身）。
  - 2026-01-26 印奇（旷视科技创始人）出任阶跃星辰董事长。
- 公司核心使命："**智能阶跃，十倍每一个人的可能**"（Scale-up possibilities for everyone）。
- 技术路线："**单模态 → 多模态 → 多模理解和生成的统一 → 世界模型 → AGI**"。

## 6. 跨界 / 影响力溢出

- **多模态卷王**：22 款自研基座模型，16 款多模态，被业内戏称"多模态卷王"。
- **开源生态**：Step-Video-T2V、Step-Audio 系列、Step-3 等多个核心模型开源。
- **产业联盟模式**：发起"模芯生态创新联盟"，是**国内首次由模型企业牵头与上游算力厂商深度合作**——为后续"模型 × 芯片"协同开创模板。
- **终端 Agent 战略**：手机（OPPO/荣耀）+ 汽车（吉利）+ IoT + 金融（券商）+ 机器人（智元/乐森）多行业终端 Agent 落地。
- **跨模态方法论**：坚持"理解生成一体化"路线，采用"原生多模方式"，与传统"三段式"形成对比。

## 7. 性格特质与认知风格

- **基础研究导向**：自评"坚持做基础大模型的公司会越来越少"——但仍坚持基础模型研发。
- **长线 + 高投入**：理解"AGI 时代需要长期投入"，不追求短期商业化。
- **科学化训练方法**：与智谱"科学训模"类似，强调"从粗放炼丹到科学训模"。
- **架构创新驱动**：MFA 注意力机制、AFD 分布式推理系统等都是底层架构突破。
- **方法论清晰**："**Scaling（已知 + 未知）+ 技术创新（架构创新 / 知识压缩 / 记忆 / 持续学习）+ 多模态感统**"是 2026 三大方向。
- **跨界 / 包容性**：吸纳前微软 + 字节 + 谷歌 + 旷视（张祥雨）等多种背景。

## 8. 失败 / 争议 / 挫折

- **"冒泡鸭"产品停运（2024-12）**：C 端产品商业化不达预期，团队合并至"跃问"（后改名为"阶跃 AI"），是 2024 年中国大模型公司中"砍 C 端、转 B 端 + 终端 Agent"的代表性事件。
- **公司副总裁李璟坦言"暂时还达不到盈利水平"**：是 AI 行业普遍问题。
- **"OpenAI 模仿者"质疑**：2024-2025 一度被批评"过于跟随 OpenAI 路线"，后通过 Step-3 原创架构和推理成本优势部分回应。
- **客户获取与定制化压力**：B 端客户决策周期长、定制化多、标准化程度低。
- **"中国版 OpenAI 路线"vs"多模态 + 推理"路线**：是少数同时押注多模态理解生成 + 推理 + 智能体 + 具身智能的创业公司，资源被广泛摊薄。

## 10. 个人哲学 / 方法论

- **"AI 三阶段演进"**：单模态 → 多模态 → 多模理解生成统一 → 世界模型 → AGI。
- **"Scaling 是已知 + 未知"**："已知是不断加数据、不断探索上限；未知是新的范式"——明确区分"数据驱动"与"科学驱动"。
- **"知识记忆 + 持续学习"**：未来模型必须具备"短期记忆、工作记忆、长期记忆"+"持续学习能力"。
- **"多模态感统"**：借鉴人类感知统合系统，让模型能统一感知视觉 / 声音 / 触觉信息。
- **"自我反思 + 自我认知"**：未来模型需要"对自我行为的解释能力"，对"我是谁、为什么是我、目标是什么"形成意义系统。
- **"中国大模型必须做多模态 + 推理 + 具身智能三栖"**：因为只有这样才能进入物理世界。
- **"以端到端 / 全异步 / 工程化的训练系统为支撑"**：RLVR + AFD + 全异步 RL 框架是阶跃星辰的方法论工具箱。
